# Personal Introduction Program

## 📌 Overview
This project is a simple Python program that takes user input and displays a personalized message.

## 🎯 Objectives
- Learn Python basics
- Use input() and print()
- Understand variables and strings

## ⚙️ Setup Instructions
1. Install Python
2. Run the file:
   python personal_intro.py

## 🧠 What I Learned
- Taking input from user
- Using variables
- Formatting output using f-strings

## 🧪 Sample Output
What is your name? Shami
How old are you? 21
What is your favorite hobby? Coding

Welcome Shami!
You are 21 years old and love Coding.
